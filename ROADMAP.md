# Roadmap

No dates or quality guarantees are implied. All six Hydra weight families are developmental.

1. **Platform foundation (current):** native Windows UI, local conversations, profiles, model registration, loopback inference, attachments, bounded retrieval, controlled workspace operations, tests and packaging.
2. **Backend/evaluation hardening:** signed runtime catalogue, resumable model downloads in the UI, hardware validation, broader markdown, accessibility and installer testing, source-backed research providers.
3. **Domain research checkpoints:** audited datasets, reproducible supervised fine-tunes, preference training, licensing review, published model cards and measured evaluations.
4. **Foundation experiments:** small dense transformers, tokenizer comparisons, compute accounting and repeatable pretraining before scale-up.
5. **Kairo/Elara specialization:** repository evaluations and verified reasoning/tool behavior.
6. **Veyra/Lumen specialization:** citation faithfulness and educator-reviewed tutoring evaluations.
7. **Multimodal:** image/document parsers and independently evaluated multimodal weights.
8. **Nyra:** integrate genuine 3D research backends with mesh validation and export tests.
9. **Orchestration:** permission-bound multi-agent scheduling and auditable execution.
10. **Frontier research:** contingent on data rights, compute, funding and demonstrated results; no current parity claim.

## Release gates still open

- Independent security review; hostile filesystem and local-process race hardening.
- Clean Windows 10/11 VM installation, repair, upgrade and uninstall matrix.
- Signed binaries, pinned inference runtime supply chain and managed model catalogue.
- Real-world generation tests across supported GPU vendors and representative weights.
- Full account service, sync, multimodal parsing, autonomous agents, MoE and RL training.

The README and validation report describe exactly what was exercised on the development machine.
